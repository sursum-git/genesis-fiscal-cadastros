# Genesis Fiscal — Cadastros

Este repositório distribui pacotes públicos de cadastros e parametrização do Genesis Fiscal para Odoo.

| Pasta | Conteúdo |
| --- | --- |
| `cadastros/` | Cadastros de referência compartilhados |
| `mensagens/` | Catálogo de mensagens |
| `programas/` | Programas e versões |
| `regras/` | Regras catalogadas |
| `ajudas/` | Ajudas e manuais |
| `edi/` | Definições e configurações portáveis de EDI |
| `parametros/` | Grupos, definições, listas e regras padrão |
| `perfis/<area>/` | Templates e valores de parâmetros publicados por área de negócio |

O assistente **Exportar Release de Perfis** gera o ZIP acumulativo e inclui o `manifest.json` na raiz, com a tag e o commit de código exigidos. Publique um ZIP homologado como anexo de cada release de dados. Este repositório recebe apenas cadastros genéricos aprovados para publicação.
